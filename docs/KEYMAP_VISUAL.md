## Layer 4-7: Windows配列（Layer 0-3の複製）

Layer 4は基本的にLayer 0と同じですが、Windows環境用に最適化されています。
Layer 5-7はそれぞれLayer 1-3に対応します。

**主な違い:**
- **親指キー配置の最適化:**
  - 左手親指: 英数キーのモッドタップを `Cmd` → `Ctrl` に変更
  - 左手親指: 中央Enterキーを `Windows` キーに変更
  - 右手親指: ESC → `Windows` キー（Mac版は `ESC`）
  - 右手親指: Cmd → `Ctrl` キー（Mac版は `Cmd`）
  - Windows環境でCtrlキーとWindowsキーを多用するため、親指でアクセス可能に配置
- **Layer 5（ファンクション・ナビゲーション）:**
  - タブ移動: `Ctrl+Tab` / `Ctrl+Shift+Tab` （Mac版は `Opt+Cmd+矢印`）
  - ブラウザ戻る/進む: ブラウザ専用キー `C_AC_BACK` / `C_AC_FORWARD` （Mac版は `Cmd+←` / `Cmd+→`）
  - その他のショートカットも `Cmd` → `Ctrl` に変更

Layer 3から→L4で切り替え、Layer 7から→L0でMac配列に戻ります。

## 特殊な動作

### モッドタップ・レイヤータップ一覧

| キー | Layer 0での動作 | 詳細 |
|------|---------------|------|
| Z | タップ: Z<br>ホールド: Shift | tap-preferred (200ms) |
| F | タップ: F<br>ホールド: Alt | tap-preferred (200ms) |
| J | タップ: J<br>ホールド: Alt | tap-preferred (200ms) |
| ; | タップ: ;<br>ホールド: Shift | tap-preferred (200ms) |
| A | タップ: A<br>ホールド: Layer 1 | 標準のlayer-tap |
| S | タップ: S<br>ホールド: Layer 3 | **カスタム** tap-preferred + hold-while-undecided |
| 英数 | タップ: 英数<br>ホールド: Cmd | tap-preferred (200ms) |
| Space | タップ: Space<br>ホールド: Layer 2 | 標準のlayer-tap |
| Enter | タップ: Enter<br>ホールド: Layer 2 | 標準のlayer-tap |
| かな | タップ: かな<br>ホールド: Layer 1 | 標準のlayer-tap |

### トラックボール動作

| レイヤー | モード | 説明 |
|---------|-------|------|
| 0, 1, 2, 4, 5, 6 | カーソル | XY軸反転あり |
| 3 | スクロール（Mac） | X軸のみ反転（Mac自然スクロール対応）<br>Sキー長押しで有効化 |
| 7 | スクロール（Windows） | XY軸両方反転（Windows標準スクロール対応）<br>Sキー長押しで有効化 |
