# キーマップ ビジュアルガイド

**凡例:**
- `↓X(n)`: レイヤータップ（ホールド→Layer n、タップ→X）
- `X(Mod)`: モッドタップ（ホールド→Modifier、タップ→X）
- `&none`: 未割り当て

**レイアウトについて:**
左右それぞれ最長7列（小指外側〜中央キー）で構成されています。各ブロックの最も内側の列が中央キー（左手: Enter/Space、右手: ESC/Cmd）です。中央上部の空きブロックは物理的にキーがない部分です。

## Layer 4-7: Windows配列（Layer 0-3の複製）

Layer 4は基本的にLayer 0と同じですが、Windows環境用に最適化されています。
Layer 5-7はそれぞれLayer 1-3に対応します。

**主な違い:**
- **親指キー配置の最適化:**
  - 左手親指: 英数キーのモッドタップを `Cmd` → `Ctrl` に変更
  - 左手親指: 中央Enterキーを `Windows` キーに変更
  - 右手親指: ESC → `Windows` キー（Mac版は `ESC`）
  - 右手親指: Cmd → `Ctrl` キー（Mac版は `Cmd`）
  - Windows環境でCtrlキーとWindowsキーを多用するため、親指でアクセス可能に配置
- **Layer 5（ファンクション・ナビゲーション）:**
  - タブ移動: `Ctrl+Tab` / `Ctrl+Shift+Tab` （Mac版は `⌥⌘+矢印`）
  - ブラウザ戻る/進む: ブラウザ専用キー `C_AC_BACK` / `C_AC_FORWARD` （Mac版は `Cmd+←` / `Cmd+→`）
  - その他のショートカットも `Cmd` → `Ctrl` に変更
- **Layer 7（スクロール・設定）:**
  - 音量調節キーを追加（Layer 3と同じ位置）
  - →L0でMac配列に戻る

Layer 3から→L4で切り替え、Layer 7から→L0でMac配列に戻ります。
